# Tecnologia para Frontend com Lógica Imperativa

Submissões para a disciplina de **Tecnologia para Frontend com Lógica Imperativa** da UNIESP.

## Conteúdo

O repositório reúne as listas de exercícios e o projeto da 2ª avaliação:

- **`src/01-prompt/`:** Lista 01: exercícios introdutórios resolvidos em Python via `input()`/`print()`.
- **`src/02-prompt/`:** Lista 02: exercícios introdutórios resolvidos em JavaScript via `prompt()`/`alert()` no navegador.
- **`src/03-json/`:** Lista 03: manipulação de dados em formato JSON com JavaScript.
- **`src/04-projeto/`:** Projeto da 2ª avaliação: site estático com páginas dinâmicas que se comunicam com uma API REST (login, envio e listagem de mensagens). Ver [README.md](./src/04-projeto/README.md) do projeto.

## Requisitos

- Python 3 (apenas para lista 01)
- Node.js v22

## Como executar

A lista 01 (Python) executa com o interpretador padrão:

```sh
python src/01-prompt/main.py
```

A lista 03 executa direto pelo Node:

```sh
node src/03-json/index.js
```

A lista 02 e o projeto da pasta `04-projeto/` executam no navegador, basta abrir o arquivo `.html` correspondente.
